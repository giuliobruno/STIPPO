# Guide screen recordings

Drop short MP4 clips (10–20s) that show the **real Stippo UI**.

| File | Command |
|---|---|
| `photo.mp4` | Capture → Photo |
| `video.mp4` | Capture → Video |
| `paste.mp4` | Capture → Paste / Share |
| `crop.mp4` | Crop a detail |
| `save.mp4` | Note + Save to vault |
| `vault.mp4` | Connect Drive / sync folder |

Optional poster stills: `photo.jpg`, `video.jpg`, …

Until a file exists, the app shows a numbered checklist placeholder for that command.
